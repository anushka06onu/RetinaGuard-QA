# Security Policy

## Reporting a Vulnerability

The RetinaGuard-QA maintainers take software security seriously. If you discover a security vulnerability or potential threat in this repository or its deployed APIs:

1. **Do not create a public GitHub issue.**
2. Please report the issue privately using **GitHub Private Vulnerability Reporting** on this repository.
3. Include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Potential impact.

We will acknowledge receipt within 48 hours and coordinate remediation before public disclosure.
